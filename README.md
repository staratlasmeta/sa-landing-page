# Star Atlas Landing Page

A landing page for Star Atlas, featuring interactive game content and community elements.

## Overview

This project contains a landing page showcasing Star Atlas gameplay, featuring:

- **Hero Section**: Video loops showcasing the game's visual appeal
- **Game Section**: Interactive carousel with gameplay videos including:
  - 3rd Person Experience gameplay
  - Top-down RTS View gameplay
  - Various game modes and fleet management features
- **Community Section**: Community-focused content with character assets

## Structure

- `index.html` - Main landing page
- `styles.css` - Styling for the landing page
- `src/` - Assets directory containing:
  - Video content for hero and game sections
  - Community character images
  - Gameplay thumbnails and media files

## Features

- Responsive design
- Video carousels for game content
- Community integration elements
- Modern web design with Star Atlas branding

## Getting Started

Simply open `index.html` in a web browser to view the landing page.
